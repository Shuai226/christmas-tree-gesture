# Christmas Tree Gesture · 手势互动圣诞粒子树

一个纯前端单文件圣诞主题互动网页：金色粒子圣诞树 + 飘雪星空 + 摄像头手势控制 + 可自定义回忆相册。

## 效果

- 深邃藏蓝星空、雪地圆形托盘、暖金背光、飘落雪花
- 数千颗金色粒子组成的圆锥圣诞树，顶部发光五角星，环绕螺旋光带，底部散落礼物盒与彩球
- 开场粒子从底部螺旋汇聚成树，周期性炸开并弹出 `CHRISTMAS 0X` 主题卡片
- 圣诞倒计时（距离下一个 12 月 25 日）

## 手势控制（摄像头本地识别，画面不上传）

基于 [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker)，在浏览器本地完成 21 个手部关键点识别：

| 手势 | 动作 |
| --- | --- |
| ✊ 握拳 | 粒子汇聚成树 |
| 🖐 张开手掌 | 粒子向外散开 |
| 🤏 拇指食指捏合 | 弹出 / 切换回忆照片 |

右侧「圣诞布置」面板内可开启手势识别；无摄像头时也可使用面板中的「汇聚 / 散开 / 照片」手动按钮兜底。

## 回忆相册

- 点击相册卡片或 `+` 号上传本地照片（JPG / PNG / WEBP），最多 8 张
- 悬停卡片点 `×` 删除；照片经压缩后保存在浏览器 `localStorage`，不上传服务器
- 已上传的照片会以漂浮相框的形式环绕在圣诞树周围；捏合手势在灯箱中逐张切换

## 运行方式

无需构建、无 npm 依赖，直接用浏览器打开 `christmas-tree.html` 即可。

> 摄像头（`getUserMedia`）要求安全上下文：本地双击 `file://` 在 Chrome / Edge 通常可用；若被浏览器拦截，请用本地服务器打开：
>
> ```bash
> # 任选其一
> npx serve .
> python -m http.server 8080
> ```
>
> 然后访问 `http://localhost:8080/christmas-tree.html`。

## 可自定义项（右侧面板）

- 星光粒子数量、主色（金 / 红 / 蓝）
- 礼物盒、彩球数量与配色（红 / 绿 / 黄）
- 展示模式：圣诞树 / 贺卡
- 背景音乐：暂停 / 播放，支持上传本地音频

## 技术栈

- 原生 HTML / CSS / JavaScript，Canvas 2D 伪 3D 投影
- MediaPipe Hands（CDN 引入）
- 无框架、无打包工具

## 调试参数

- `?ready=1`：跳过开场汇聚动画，直接展示成型的树
- `?panels=1`：默认展开左右两侧面板
